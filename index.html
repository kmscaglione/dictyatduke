dictyBase

A community resource for Dictyostelium and related social amoebae — searchable gene records, sequenced genomes, structures, and curation tools. This is a beta build; data and features are still being validated, so please report anything that looks off.

Data sources

  • Legacy dictyBase (Basu et al. 2015)
  • UniProt
  • NCBI Gene
  • AlphaFold (EMBL-EBI)
  • VEuPathDB / AmoebaDB
